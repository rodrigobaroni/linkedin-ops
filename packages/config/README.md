# @linkedin-ops/config

Shared tooling for every workspace: `tsconfig.base.json` (+ `tsconfig.library.json`, `tsconfig.app.json`), ESLint flat config (`@linkedin-ops/config/eslint`), Prettier (`@linkedin-ops/config/prettier`) and Vitest defaults (`@linkedin-ops/config/vitest`). Tailwind and dependency-direction rules arrive with T-007 / T-004.
