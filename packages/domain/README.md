# @linkedin-ops/domain

Domain layer shared by `apps/api` and `apps/worker` (ADR-0001 structure amendment): entities, content
state machine, autonomy policy, application services and the Prisma data layer.

## Data layer (T-005)

- `prisma/schema.prisma` — source of truth for the TypeScript types; mirrors `docs/architecture/data-model.md`.
- `prisma/migrations/` — SQL migrations (`migration.sql`) with a reviewed `down.sql` each.
- `prisma/seed.ts` — idempotent development seed (fictitious data only).
- `src/client.ts` — `createPrismaClient({ connectionString })` on the `pg` driver adapter.
- `src/ids.ts` — `newId()` (uuid v7, generated by the application).
- `src/generated/` — Prisma Client output; regenerated by `pnpm generate`, never committed.

Scripts: see the `db:*` entries in the root `package.json` and `docs/runbooks/database-migrations.md`
(PT-BR). `pnpm test` runs unit tests only (enum parity with `@linkedin-ops/contracts`);
`pnpm test:integration` needs Docker (Testcontainers) and runs in the `db-integration` CI job.
